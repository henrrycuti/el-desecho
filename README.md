# El Desecho

Juego de terror por capítulos en primera persona, para Android y Windows, hecho en Unity 6000.6.5f1 (URP).
Un periodista baja a las alcantarillas de la ciudad siguiendo una pista sobre un laboratorio secreto.

- Historia completa: [Docs/HISTORIA_EL_DESECHO.md](Docs/HISTORIA_EL_DESECHO.md)
- Estructura por capítulos y plan: [Docs/ESTRUCTURA_CAPITULOS.md](Docs/ESTRUCTURA_CAPITULOS.md)
- Decisiones sobre la historia: [Docs/DECISIONES_HISTORIA.md](Docs/DECISIONES_HISTORIA.md)

## Abrir y jugar

1. Abre la carpeta del proyecto en Unity Hub con Unity 6000.6.5f1.
2. Menú **El Desecho > Construir prólogo** para generar las escenas.
3. Abre `Assets/ElDesecho/Scenes/Menu.unity` y pulsa Play.

Controles en PC: WASD caminar, ratón mirar, Shift correr, C agacharse, F linterna, E usar, Esc pausa. En teléfono: joystick a la izquierda, arrastrar a la derecha para mirar y botones de acción.
